# Agentic AI

This is a memo by author, for you to understand the context and history of the project.

## 1. Inspiration

There are several projects that inspired me to start this project:

- [ ] [Code Switch](https://github.com/daodao97/code-switch)
- [ ] [CC Switch](https://github.com/farion1231/cc-switch)

These projects are great, it enabled the individual developer to use Agentic Tools especially for coding, but they have limited feature to support a team.

## 2. Problem

I came up with a strong background in sofeware development in differnet size of teams, from 2 people to 200 people. I could see the huge impact of Agentic Coding to the orgnaization. Thus, I started to think about how to use Agentic Tools to support a team to develop software.

Seating on my position, I need to consider the following aspects when I rolling Agentic Coding in a larger scale (instead of individual developer):

- Cost Control: How to control / monitor the cost of Agentic Coding?
- Education: How to educate the team to use Agentic Coding effectively? How to apply the best practice?
- Security: How to ensure the code is secure and compliant?
- Compliance: How to ensure the code is compliant with the company policy?

I might have bigger ambition to get the Return on Investment (ROI), but I do know, without the above aspects, it is hard to get the ROI.

That's why I try to develop such tool to help team manager and company leaders to adapt Agentic Coding in their team.
