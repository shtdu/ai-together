# Compliance

Code Together is designed to comply with relevant data protection and security regulations.

## Purpose

Document the system's compliance posture and certifications.

## Regulations and Standards

### GDPR (General Data Protection Regulation)

**Status:** Compliant

**How we comply:**
- **Data Minimization:** Only collect metadata, not content
- **Purpose Limitation:** Data used only for analytics
- **User Rights:** Users can access, export, delete their data
- **Right to be Forgotten:** Data deleted per retention policy or upon request
- **Data Portability:** Users can export their data
- **Consent:** Users consent to data collection through use

**Data Storage Location:**
- Default: United States
- Commercial options: Data residency available (upon request)

### SOC 2 Type II

**Status:** Not certified

**What SOC 2 covers:**
- Security
- Availability
- Processing Integrity
- Confidentiality
- Privacy

> **PLANNED** - SOC 2 Type II certification is planned for a future release.

### ISO 27001

**Status:** Not certified

**What ISO 27001 covers:**
- Information security management system
- Risk management
- Security controls

> **PLANNED** - ISO 27001 certification is planned for a future release.

## Data Residency

**Default:**
- Data stored in United States

**Commercial Options (Planned):**

> **PLANNED** - Data residency options beyond US are planned for a future release.

## Data Processing Agreement

**For Business Customers:**
- DPA available for Commercial licenses
- Outlines data processing responsibilities
- Data protection commitments
- Breach notification procedures

## Data Breach Notification

**Our Commitment:**
- Notification within 72 hours of discovery (where legally required)
- Clear description of what happened
- What data was affected
- What we're doing to fix it
- What users can do to protect themselves

**Breach Notification Includes:**
- Affected users notified via email
- Public announcement if required
- Regulatory notification where required

## Access Controls

**Employee Access:**
- Principle of least privilege
- Access logged and audited
- Annual security training required

**Third-Party Access:**
- No third-party data sales
- Limited access for support (only with user permission)
- All access logged

## User Rights Under GDPR

### Right to Access

**Users can:**
- View all data collected about them
- Export their personal data
- Request data summary

**How:** Export feature in Member app, contact support for full report

### Right to Rectification

**Users can:**
- Correct inaccurate data
- Complete incomplete data

**How:** Contact support@code-together.com (placeholder)

### Right to Erasure (Right to be Forgotten)

**Users can:**
- Request account deletion
- Have their data permanently deleted

**How:**
1. Contact manager (for team accounts) or support
2. Request account deletion
3. Data deleted within 30 days (suggested)
4. Confirmation email sent

### Right to Portability

**Users can:**
- Export their data in structured format
- Receive in CSV or JSON format

**How:** Export feature in Member app

### Right to Object

**Users can:**
- Object to processing (automated decision making)
- Request human review

**How:** Contact support@code-together.com (placeholder)
