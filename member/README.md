# Member Client

## Frontend Assets (for go:embed)
`main.go` embeds `frontend/dist`, which is generated by the frontend build. In a clean checkout, build the frontend once:

```sh
cd member/frontend
npm install
npm run build
```

or

```sh
go install github.com/wailsapp/wails/v3/cmd/wails3@latest
wails3 task common:build:frontend
wails3 task darwin:build
```

## Development (Go + Vue Reload)
Use Wails dev mode to get backend reloads and Vue hot reload:

```sh
wails3 dev -config ./build/config.yml -port 9245
```
